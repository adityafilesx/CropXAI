# Reproducibility

Run commands from the repository root with the supplied virtual environment. The dependency lock records observed installed versions; a clean install has **not** been verified. PyPI name resolution failed during the revision; unittest is used without installing pytest. The final campaigns ran on an Apple-silicon laptop (MPS, deterministic algorithms enabled). Never present smoke results as full benchmark results.

```sh
./cropxai environment
./cropxai validate-dataset                       # RGB + GeoTIFF manifests, pairing, band-order evidence
python -m unittest discover -s tests -p 'test_revision*.py' -v
./cropxai smoke
./cropxai campaign run --config configs/experiments/revision_v1.json
./cropxai campaign run --config configs/experiments/revision_v1_prithvi_ms6.json
./cropxai analyze && ./cropxai compliance
./cropxai figures && ./cropxai paper build
./cropxai validate-manuscript
./cropxai paper package                          # reviewer package
```

For a single run use `--model ResNet-18 --seed 42` with the full configuration. GPU execution uses `device: auto` (CUDA first), or set an explicit device in a new versioned configuration. Never change settings mid-campaign. Backbone features are cached with checkpoint, input selections, split hash, normalization, implementation and framework version; cache hashes are checked on read. Gradient explanations still use the actual image model. Caches are derived artifacts and are excluded from public source packages.

Do not rerun a seed blindly: each attempt is preserved under a distinct run ID. The analyzer rejects duplicate seeds in a group instead of choosing the best result. Original databases are never overwritten/deleted. Additive SQLite tables `revision_schema` and `revision_runs` store new immutable records; original tables remain. JSON records include errors for failed runs. No fallbacks fill missing metrics. Each successful run saves model weights, probabilities, labels, sample IDs, embeddings, corruption predictions, explanations and per-epoch history. Actual numerical reproducibility is platform-dependent; source hashes and environment versions make differences inspectable.

Legacy commands such as `./cropxai campaign run --epochs ...` are superseded by versioned JSON configurations. Both `./cropxai` and the installed entry point now select the same CLI. The legacy `src/research` tree is retained for audit but not advertised as functional research software. Original paper files are preserved and the revised source is built separately under paper/source. Build output is a draft until the submission validator and external requirements are satisfied.

No genuine similarity report, author license decision, or conference portal upload is generated by this code. A public release is not verified. Prithvi-EO-1.0-100M must be downloaded at the pinned revision (see README); its SHA-256 is verified at load time.
