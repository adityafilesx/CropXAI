## C. Claims that are inference-only or could not be fully supported

1. **Which execution Figure 7 came from.** Inferred, not proven. Evidence: the convergence figure's axis (validation ~84-86 %, loss to ~0.50) matches the reviewer-DB run; `baseline_results.pdf` prints that run's exact test accuracy and T3; the DB registers it 89.6 s after the run timestamp. Not available: the convergence figure's plotted data, its generating script, any per-epoch log. (File modification times also suggest `training_curve.pdf` was written ~11 minutes *before* that run's timestamp - weak filesystem metadata, deliberately not used in the paper; it would imply an even earlier, unstored execution.)
2. **Figure numbering.** In the extracted text of the submitted PDF the training-dynamics figure is Fig. 8 and Fig. 7 is a cross-dataset drift plot; the reviewer brief calls the convergence figure "Figure 7". The wording must be compared with the real notification.
3. **EuroSAT processing level.** The dataset paper (arXiv ar5iv text searched this session) does not state Level-1C or top-of-atmosphere; it says B01, B09 and B10 are intended for atmospheric correction. "Apparently Level-1C" rests on the presence of B10, which Level-2A products omit (general Sentinel-2 knowledge, not verified from a primary source here). The dataset identifier string `EuroSAT-MS-Sentinel2-L1C-GeoTIFF` in the manifests/code carries the same inference and cannot be renamed without changing the run-identity hash.
4. **"Published Prithvi results use fine-tuning".** Supported by the model card's fine-tuning examples and the cited paper's downstream-task framing; the paper's full text was not re-read in this session.
5. **Weights fixed before the final campaign.** Supported by the configuration file's modification time (21 Oct) versus the campaigns (22-23 Oct); filesystem time stamps are weak evidence.
6. **Equations vs implementation.** Read against the code by the revising software; no automated test compares the LaTeX equations with the code.
7. **Reviewer comment wording** follows the author brief, not the original email (see Task 3).
8. **Template/page limit/filename rule.** Unknown: the official guide returns HTTP 403 and no notification text was supplied.
9. **Similarity percentage.** No report supplied; nothing is claimed.
10. **Single re-execution of the legacy trainer** (n = 1) supports "reproducible with current code", not statistical determinism.
