# Similarity report - how to obtain a genuine one

No similarity report exists in this repository and none was simulated. The conference requires a separate report (<= 10 % similarity for the revised manuscript) from an accepted similarity-detection service.

1. Upload `output/pdf/445_revised_version.pdf` (manuscript **and** response) or, if the service accepts it, only the manuscript pages 1-14 (before "Point-by-point response").
2. Save the service's own PDF report as `output/pdf/similarity_report.pdf`. The manuscript gate (`./cropxai validate-manuscript`, check `similarity_report`) only checks that the file exists; the authors must read the percentage and the matched sources themselves.
3. Likely sources of matches: the quoted reviewer comments in the response section; the Procedia boilerplate (copyright/licence lines); the reference list; the authors' own earlier text from the submitted version (cite it, do not paraphrase to evade detection).
4. If the percentage exceeds the limit, quote or cite genuinely shared passages and shorten the response wording; do not alter technical content or numbers.
